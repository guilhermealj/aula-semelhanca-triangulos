# Aula 7 · Semelhança de triângulos

Aula interativa MatMov sobre razão, proporção, semelhança de triângulos e Teorema de Tales.

[Abrir a aula](https://guilhermealj.github.io/aula-semelhanca-triangulos/)

90 minutos de conteúdo, figuras interativas e resoluções progressivas. Use as setas para navegar, M para o índice, C para consulta e F para tela cheia.

O botão Professor abre o controle de participação. Compartilhe somente a guia da aula.

As fontes incorporadas são acompanhadas pelas respectivas licenças OFL.
